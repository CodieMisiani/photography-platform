# Adding Images to Malume

This document explains how to add and manage images in the Malume photography platform for non-technical users (photographers, content editors).

- Image sizes: upload JPG/PNG. Recommended dimensions: 3000px on the long edge for full-bleed hero images; 1200px for portfolio thumbnails.
- Compression: export with quality 75–85. Use tools like ImageOptim, Squoosh, or Photoshop "Save for Web".
- Filenames: use descriptive, hyphen-separated names (e.g. `maternity-session-2026-05.jpg`). Avoid spaces and special characters.
- Alt text: always provide descriptive alt text for accessibility. Keep it concise (5–15 words) and descriptive of the scene.
- Aspect ratio: prefer 4:3 for portfolio grid, 16:9 for hero sections.
- Metadata: include capture date, location, and credits in the image caption field when available.
- Cloudinary: when connected, images are uploaded and transformed automatically. If Cloudinary is not configured, contact the site administrator to upload via admin CMS.

If you need a quick checklist for preparing images, ask the site admin to provide source files and we will optimize and upload them.
